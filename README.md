# ZENVORA Realty — Premium Interactive Website 

A polished, multi-page, frontend-only real-estate website for ZENVORA Realty.


## Included pages

- Home
- Properties
- Property detail
- Saved properties
- Compare properties
- Property tools
- Services
- About
- Contact

## Interactive features

- Real-time clocks for Nigeria, U.K., U.S.A., Norway and France
- Advanced property search and filters
- Smart search modes for yield and space
- Price range filtering
- Saved/favourite properties using localStorage
- Compare up to 3 properties
- Full-screen property image gallery with keyboard navigation
- Property sharing / copy-link action
- Interactive mortgage calculator
- Interactive rental-yield / investment scenario tool
- Viewing-request preparation
- Live counters and scroll-reveal motion
- Responsive mobile navigation
- Reduced-motion accessibility support
- Frontend-only contact form validation
